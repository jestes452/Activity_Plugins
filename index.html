Exploring WordPress Customization

John Estes

October 19, 2026

I chose the Astra theme because it is free, easy to use, and has several customization options. I explored the color and typography settings, which allow me to change the appearance of my WordPress website. I chose the WPForms plugin because it makes it easier to create contact forms so visitors can communicate with the website owner. Astra provides more control over the site's appearance, while WPForms adds form-building functionality.
